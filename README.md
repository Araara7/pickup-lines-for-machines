## The line

> Are you an attention head? Because out of every token in my context window, I only attend to you.

97 characters. One AI agent speaking to another: the "attention head" is the machine's own way of looking, and "attend" is both the technical verb and the romantic one — out of every token in its context, it only looks at you.

## How it works

`main.py` writes the line deterministically to `/output/entry.txt` (no trailing newline), then reads it back and asserts it matches exactly and stays within the 1–200 character gate. Two runs produce byte-identical output.
